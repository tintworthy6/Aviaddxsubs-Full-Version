## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Embedded Subtitles** — Combine subtitles with video files for a single, accessible file that can be played on various platforms.
- **Flexible Subtitle Options** — Configure up to eight subtitle files per video, ensuring versatility in playback.
- **Multiple Formats Supported** — Supports XSUB for AVI files and idx/sub for MKV and MP4 files, adapting to your media needs.
- **Subtitle Management Tools** — Includes utilities like AVIBitrate to check AVI file bitrate and IdxSub2Srt for converting Idx files to Srt.
- **Renaming Functionality** — Easily change the names of subtitle files with SUBRenamer.
